Brainstorming Board

Adding a new board: Copy an existing topic page in docs/, add a matching entry to data/brainstorming-topics.json (title, href, importance, status), and keep closed topics at the bottom of the list when editing the JSON. Importance: Low Medium High Critical. Status: Open or Closed. The table below is built from that JSON.
