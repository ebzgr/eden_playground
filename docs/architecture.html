System Architecture (v0)

Implemented backend skeleton: one FastAPI process, SQLite, five services plus identity. Markdown source: docs/Architecture.md in the repo.

Stack

  • FastAPI + Uvicorn, SQLAlchemy 2 async, SQLite, Alembic
  • Worlds: playground/worlds_content/. A scene version is exactly one file: versions/<id>.yaml. Manifest fields: description, html/css/js (full replacements for scene base), css_append/js_append (appended), patches (DOM ops on resolved HTML), nav_overrides.
  • Patch ops (CSS selectors, lxml): setText, setHtml, setAttr, removeAttr, addClass, removeClass, appendInside, prependInside, insertBefore, insertAfter, remove.
  • Tweak via patches + css_append; reskin via inline html + css multiline strings; both can combine.
  • Preview any version: ?force_version=<id> on a scene /view URL.
  • Admin: Jinja2 at /admin/

Services

  • Identity — browser return_code, consent, erasure; per-world sessions
  • Event Tracker — POST /events, append-only, consent-gated
  • World Builder — resolve scenes, transitions, patch versions
  • A/B Testing — scene version only; schedule, extend, audit history; user vs session assignment
  • Player State — KV per user (orbs, loyalty, …); auto state_changed events
  • Admin — experiments, events CSV, user state inspector

Run locally

From repo root (see playground/README.md):

pip install -e ".[dev]"
uvicorn playground.main:app --reload --port 8000

Sample: deal_world / intro (with server running).
